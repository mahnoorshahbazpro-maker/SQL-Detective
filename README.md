# 🕵️ SQL Detective

**An interactive SQL investigation game built with Python, MySQL, Pandas, and Streamlit.**

## Project Overview

SQL Detective is a beginner-friendly data analytics project in which users investigate a fictional e-commerce sales mystery by writing SQL queries and analyzing database records.

## 🎯 Investigation Missions

1. Identify the product with the highest revenue.
2. Find the city generating the most revenue.
3. Identify the product category with the lowest revenue.
4. Find the customer who placed the most orders.

## ✨ Features

* MySQL database connectivity
* Interactive SQL query console
* Four investigation missions
* Score tracking and hints
* Query results displayed in a table

## 🛠️ Technologies

* Python
* SQL and MySQL
* Pandas
* Streamlit

## 🚀 Run Locally

1. Install Python and MySQL.

2. Install dependencies:

   `pip install -r requirements.txt`

3. Create and populate the `ecommerce_analysis` database with the required tables and sample data.

4. Run the application:

   `streamlit run app.py`

5. Enter your MySQL credentials in the sidebar to connect.
